# Feature File Field To Excel Mapping

This project does not use AI while generating Excel. The Excel values come from:

1. the Scenario / Scenario Outline name
2. the step lines: Given, When, Then, And, But
3. the Examples table columns
4. the tags above each Examples block

Each Examples data row creates one Excel test case row.

## Excel Columns

| Excel Column | How It Is Created |
| --- | --- |
| ID | Auto-generated by the tool as TC-001, TC-002, TC-003, etc. |
| Labels | Uses Examples column `Labels` or `Label`. If missing, uses tags above Examples, without `@`; `_En` / `_Fr` suffix is removed. |
| Lan | Uses Examples column `Lan`, `Lang`, or `Language`. If missing, detects from tags ending `_En` or `_Fr`. Default is EN. |
| Test Summary | Uses Examples column `TestSummary` if provided. If missing, builds from `Application`, `Lan`, `UserRole`, `Page`, `MainFields`, `NotificationType`, `NotificationName`, `State`. If not enough fields exist, uses the resolved Scenario Outline title. |
| Description | Uses Examples column `Description` if provided. If missing and `NotificationText` plus `NotificationCategory` exist, builds notification description. Otherwise uses `Verify that <test summary>.` |
| Action | All `Given` and `When` steps, plus `And` steps before the first `Then`. Placeholders like `<SSOUser>` are replaced from Examples values. |
| Expected Result | First `Then` step and following `And` steps. If another `When` appears later, following lines move back to Action until next `Then`. |
| Data | Uses Examples column `Data`. |
| Auto Assessment | Uses Examples column `AutoAssessment` or `AutoAssessmentStatus`. Default is `A: In Sprint Automation`. |
| POD | Uses Examples column `POD`. Default is `Batman`. |
| MALCODE | Uses Examples column `MALCODE` or `MALCODEValue`. Default is `HOJ`. |
| Test Repository Path | Uses Examples column `TestRepositoryPath`, `RepositoryPath`, or `TestRepoPath`. |

## Important Rules

- One Examples row equals one Excel test case.
- A Scenario Outline with 4 Examples rows creates 4 Excel rows.
- A scenario with no `Then` creates a blank Expected Result.
- Use `\n` inside an Examples cell when Excel should show line breaks.
- If you need exact company-style Test Summary, provide the metadata fields in Examples.

## Recommended Examples Columns For Company Output

Use these columns when you want meaningful Excel output:

```gherkin
| Labels | Lan | Application | UserRole | UserDisplay | Page | MainFields | NotificationType | NotificationName | State | NotificationText | NotificationCategory | AutoAssessment | POD | MALCODE | TestRepositoryPath |
```

For normal functional flows where notification fields do not apply, use explicit `TestSummary` and `Description`:

```gherkin
| Labels | Lan | TestSummary | Description | SSOUser | MMSUser | AutoAssessment | POD | MALCODE | TestRepositoryPath |
```

Automation Repository Explorer

Static analysis for Java Selenium Cucumber automation repositories. ARE maps features, scenarios, steps, step definitions, page objects, wrapper methods, property keys, and XPath locators without AI.

Python 3.12+ Local Streamlit Static Analysis Read Only No LLMs No Vector DB

Repository Mapping

Feature File
  -> Scenario
  -> Step
  -> Step Definition
  -> Java Method
  -> Page Object
  -> Wrapper Method
  -> Property Key
  -> XPath

Run Locally

python -m venv .venv
source .venv/bin/activate
pip install -r requirements-dev.txt
python run_local.py

Run ARE on the same laptop or workstation where the automation repository exists. Paste the repository folder path in the sidebar and scan it. ARE does not upload, copy, deploy, or modify the repository.

Version 1 Features

Repository Scanner

Recursively indexes .feature, .java, .properties, .json, and .xml files.

Parsers

Extracts features, scenarios, steps, examples, Java methods, annotations, calls, and properties.

Relationship Graph

Builds bidirectional links for forward and reverse mapping.

Search

Supports exact, partial, case-insensitive, and RapidFuzz fuzzy search.

Local-Only Note

This project page can be hosted as static documentation, but the ARE application is designed for local execution. Cloud-hosted Streamlit apps cannot scan local paths such as C:\Users\... or /Users/... on your laptop.
